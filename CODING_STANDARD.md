# Стандарт кодування проєкту UtilityBills

## 1. Загальні положення
Цей документ фіксує домовленості щодо іменування та форматування коду в проєкті. Усі правила закріплені машинно у файлі .editorconfig.

## 2. Іменування

| Сутність | Конвенція | Приклад | Антиприклад |
|---|---|---|---|
| Клас, запис | PascalCase, іменник | UtilityBill | utilitybill |
| Інтерфейс | I + PascalCase | IBillRepository | Repository |
| Метод | PascalCase, дієслово | CalculateTotal | calc |
| Властивість | PascalCase, іменник | Tariff | GetTariff |
| Приватне поле | _ + camelCase | _lines | m_Lines |
| Локальна змінна | camelCase | totalAmount | ta |
| Константа | PascalCase | MaxVolume | MAX_VOL |
| Перелічення | PascalCase однина | BillStatus | BillStatuses |

## 3. Форматування
1. Відступ становить 4 пробіли табуляція заборонена.
2. Довжина рядка обмежена 100 символами.
3. Фігурні дужки пишуться у стилі Allman і є обов’язковими навіть для однієї інструкції.
4. Між членами класу залишається рівно один порожній рядок.
5. Директиви using пишуться на початку файлу системні йдуть першими.
6. Простір імен оголошується на рівні файлу.

## 4. Коментарі та документація
Коментарі мають пояснювати причину рішення а не дублювати код.
___
// погано

// множимо обсяг на тариф

sum += line.Volume * line.Tariff;
___
// добре

// тариф для пільговиків фіксується на рівні базового

sum += line.Volume * BaseTariff;

## 5. Структура проєкту
Проєкт поділено на бібліотеку класів з доменною логікою та консольний застосунок для виведення результатів.

## 6. Правила комітів
Коміти пишуться в наказовому способі за конвенцією Conventional Commits наприклад feat, fix, chore.

## 7. Правила, закріплені машинно

| Пункт стандарту | Механізм перевірки | Правило |
|---|---|---|
| Відступ 4 пробіли | .editorconfig | indent_size = 4 |
| Приватне поле з _ | аналізатор іменування | IDE1006 |
| Дужки обов’язкові | .editorconfig | csharp_prefer_braces |
| Немає зайвих пробілів | StyleCop | SA1028 |
| Порядок членів класу | StyleCop | SA1201 |
| Формат коду загалом | dotnet format | IDE0055 |

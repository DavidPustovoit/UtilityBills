# Класова модель предметної області: Нарахування комунальних платежів (UtilityBills)

## 1. Сутності та інваріанти

| Сутність | Роль | Незмінний | Головний інваріант |
| :--- | :--- | :--- | :--- |
| **BillLine** | Позиція документа | Так, `record` | `Volume > 0`, `TariffRate >= 0` |
| **UtilityBill** | Документ зі станом | Ні, агрегат | `Id > 0`; позиції можна додавати лише у стані `Draft` |
| **Subscriber** | Довідник учасників | Так, `record` | `Email` містить `@`, `FullName` не порожнє |
| **ServiceTariff** | Довідник обліку | Ні (тариф може змінюватись) | `PricePerUnit > 0`, `ServiceName` не порожнє |

## 2. Життєвий цикл документа (UtilityBill)

| Зі стану | До стану | Умова |
| :--- | :--- | :--- |
| `Draft` | `Issued` | Є хоча б одна позиція (BillLine) |
| `Draft` | `Cancelled` | Завжди |
| `Issued` | `Paid` | Завжди |
| `Paid` | `Archived` | Після зарахування коштів |

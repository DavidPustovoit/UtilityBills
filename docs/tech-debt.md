# Реєстр технічного боргу

| Проблема | Тип боргу | Чому це заважає | Можливе рішення |
|---|---|---|---|
| `DateTime.Now` в конструкторі | Тестовий / Архітектурний | Робить неможливим точне тестування дати створення (недетермінованість). | Використовувати `TimeProvider` (у .NET 8) або передавати інтерфейс `IClock`. |
| Захардкоджені константи знижок | Архітектурний | Бізнес-правила (ПДВ 20%, знижки) вшиті в код. Для зміни потрібен реліз. | Винести фінансові налаштування в інтерфейс `ITaxPolicy` / `AppConfig`. |
| Метод `FindById` в сутності | Дизайнерський | Сутність знає про масив собі подібних. | Перенести пошук до `BillRepository`. |
